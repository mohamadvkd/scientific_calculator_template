# Scientific Calculator — Klencod Template

قالب Flutter لآلة حاسبة علمية احترافية يعمل دون اتصال ولا يحتاج إلى حزم خارجية.

## المزايا

- العمليات الأساسية والأسس والنسب المئوية والعاملية.
- الدوال `sin` و`cos` و`tan` و`log` و`ln` و`sqrt`.
- التبديل بين DEG وRAD.
- سجل العمليات مع إعادة استخدام أي نتيجة.
- ذاكرة `M+` و`M-` و`MR` و`MC`.
- نسخ النتيجة إلى الحافظة.
- واجهة داكنة مناسبة للاستخدام الطويل.
- محرك تقييم داخلي قابل للاستبدال بخدمة حساب أكثر تقدمًا.

## التشغيل

يجب أن يبقى `pubspec.yaml` في جذر المشروع مع مجلد `android`. استورد المجلد كاملًا داخل Klencod IDE ثم شغّل Build APK.
